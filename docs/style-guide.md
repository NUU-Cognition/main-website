## Logo Overview

The NUU Cognition logo is a minimalist geometric mark that embodies the company's mission to enhance human thinking through innovative cognitive tools. The design features a bold "V" shape within a square frame, representing victory, vision, and the vertical integration of knowledge layers.

### Core Design Elements

- **The Nu Symbol (ν)**: The 13th letter of the Greek alphabet, representing:
  - **Scientific Heritage**: Nu is commonly used in physics for frequency, linking to cognitive frequency/wavelength
  - **New/Novel**: Phonetically connects to "new" - new ways of thinking
  - **Mathematical Precision**: Greek letters symbolize rigorous, systematic thinking
- **The Square Frame**: Symbolizes structure, stability, and the systematic approach to cognitive enhancement
- **Negative Space**: Creates a dynamic interplay suggesting depth and multiple layers of understanding

---

## Design Philosophy

### Conceptual Alignment

The logo reflects NUU Cognition's core principles:

1. **Hierarchical Thinking**: The V shape mirrors the layered abstraction approach of TextSurf, allowing users to "zoom" through levels of information
2. **Cognitive Expansion**: The upward-opening form suggests growth and enhanced mental capacity
3. **Structural Innovation**: The geometric precision reflects the systematic, engineering-based approach to metacognition
4. **Active Engagement**: The bold, dynamic form encourages interaction rather than passive consumption

### Visual Metaphors

- **The Greek Nu (ν)**:
  - Scientific and academic credibility
  - Frequency of thought (nu = frequency in physics)
  - The "new" in cognitive enhancement
- **The Valley**: Represents the gap in current cognitive tools that NUU Cognition aims to fill
- **The Victory Mark**: Symbolizes overcoming cognitive limitations
- **The Viewport**: Suggests a new lens through which to view and process information

## Logo Construction

### Grid System

The logo is constructed on a 5x5 grid system for perfect proportions:

```
┌─────────────────┐
│  ┌─┬─┬─┬─┬─┐  │
│  ├─┼─┼─┼─┼─┤  │
│  ├─┼─┼─┼─┼─┤  │
│  ├─┼─┼─┼─┼─┤  │
│  ├─┼─┼─┼─┼─┤  │
│  └─┴─┴─┴─┴─┘  │
└─────────────────┘
```

### Proportions

- **Outer square**: 100 units x 100 units
- **Border width**: 10 units
- **V-shape angle**: 45° from vertical
- **V-shape thickness**: 20 units
- **Bottom point position**: Centered, 10 units from bottom edge

## Typography

### Primary Typeface: Inter

- **Weights**: Light (300), Regular (400), Medium (500), Bold (700)
- **Usage**: All product interfaces, marketing materials, documentation
- **Characteristics**: Clean, highly legible, excellent for digital interfaces

### Secondary Typeface: Space Grotesk

- **Weights**: Regular (400), Medium (500), Bold (700)
- **Usage**: Headlines, emphasis, technical documentation
- **Characteristics**: Geometric, modern, reflects the engineering mindset

### Logo Lockups

When combining the logo with text:

- **Minimum spacing**: 1.5x the height of the V-mark
- **Alignment**: Bottom-aligned with the square frame
- **Type size**: 0.8x the height of the square frame

## Clear Space & Minimum Size

### Clear Space

Maintain a clear space around the logo equal to the width of the V-shape stroke (X):

```
┌─────────────────────┐
│         X           │
│    ┌─────────┐      │
│ X  │    V    │  X   │
│    └─────────┘      │
│         X           │
└─────────────────────┘
```

### Minimum Sizes

- **Digital**: 24px x 24px
- **Print**: 0.5" x 0.5" (12.7mm x 12.7mm)
- **Favicon**: 16px x 16px (simplified version)

## Logo Variations

### 1. Primary Logo

- Full black logo on white background
- Standard application for most use cases

### 2. Reversed Logo

- White logo on black or dark backgrounds
- Maintains full visibility and impact

### 3. Monochrome Variations

- Single color applications for limited color environments
- Maintains logo integrity without tonal variation

### 4. Icon Version

- Square V-mark without company name
- For app icons, favicons, and space-constrained applications

### 5. Horizontal Lockup

```
[V] NUU COGNITION
```

- For wide format applications
- Maintains proportional relationships

### 6. Stacked Lockup

```
  [V]
  NUU
COGNITION
```

- For square format requirements
- Centered alignment

## Usage Guidelines

### Do's

- ✓ Use the logo at recommended minimum sizes
- ✓ Maintain proper clear space
- ✓ Use approved color variations
- ✓ Ensure high contrast between logo and background
- ✓ Use vector files for scalability
- ✓ Apply consistently across all touchpoints

### Don'ts

- ✗ Don't rotate or skew the logo
- ✗ Don't change the proportions
- ✗ Don't add effects (shadows, gradients, outlines)
- ✗ Don't use unapproved colors
- ✗ Don't place over busy backgrounds
- ✗ Don't recreate or redraw the logo

## Application Examples

### Digital Applications

1. **Product Interfaces**

   - Top-left corner placement in TextSurf and other COS apps
   - 32px height for desktop, 24px for mobile

2. **Website Header**

   - 40px height
   - Linked to homepage
   - Paired with navigation elements

3. **App Icons**

   - iOS: 1024px x 1024px master
   - Android: 512px x 512px master
   - Adaptive icon with safe zones

### Print Applications

1. **Business Cards**

   - 0.75" x 0.75" placement
   - Top-left or centered

2. **Documents**

   - 1" x 1" for letterhead
   - 0.5" x 0.5" for reports

3. **Merchandise**

   - Minimum 2" x 2" for apparel
   - High-quality printing methods only

### Environmental Applications

1. **Office Signage**

   - Minimum 6" x 6"
   - Cut vinyl or dimensional letters

2. **Trade Show Displays**

   - Proportionally scaled
   - High-resolution files required

## Incorrect Usage

### Common Mistakes to Avoid

1. **Distortion**

   - Never stretch or compress the logo
   - Always scale proportionally

2. **Color Modifications**

   - Don't use gradient fills
   - Don't apply transparency to the mark
   - Don't use colors outside the approved palette

3. **Compositional Errors**

   - Don't separate the V from the square
   - Don't add additional elements
   - Don't place text inside the square

4. **Background Issues**

   - Avoid low contrast combinations
   - Don't place over complex patterns
   - Ensure legibility at all times
